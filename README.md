# JSONPlaceholder API Test Automation

Automated API testing project built with **TypeScript** and **Playwright**, targeting the [JSONPlaceholder](https://jsonplaceholder.typicode.com) REST API.

This project was built to strengthen skills in API test automation, clean architecture, and best practices like KISS, DRY, and Clean Code.

---

## 🛠️ Tech Stack

| Tool | Purpose |
|---|---|
| [TypeScript](https://www.typescriptlang.org/) | Strongly typed language |
| [Playwright](https://playwright.dev/) | Test framework & HTTP client |
| [Node.js](https://nodejs.org/) | Runtime environment |
| [GitHub Actions](https://github.com/features/actions) | CI/CD pipeline |

---

## 🏗️ Architecture

```
tests/
├── fixtures/       # Reusable test setup and test data
├── specs/          # Test suites organized by resource
└── helpers/        # Custom assertions and utilities
```

---

## 🚀 Getting Started

### Prerequisites

- Node.js >= 18
- npm >= 9

### Install dependencies

```bash
npm install
```

### Run tests

```bash
npm test
```
